Project developed by Danial Zolfaghari (دانیال ذوالفقاری). AI / ML · Razhman.

Project overview

AI-powered network/security intelligence platform — federated Elasticsearch discovery, governed semantic World Map, and bilingual NL investigations through validated live query execution.

AI Data Analyzer (Network Intelligence Command Center) connects to multiple Elasticsearch clusters, discovers schema semantics through bounded sampling, builds a governed World Map knowledge graph, and answers Persian/English natural-language questions via the AI Operator — routing every live query through validated InvestigationPlans before execution.

Replaces manual KQL/DSL authoring with governed NL investigations — semantic authority separation ensures vector similarity never auto-authorizes production Elasticsearch queries.

Security and network analysts needed to investigate federated Elasticsearch environments across multiple clusters — but querying required deep KQL/DSL expertise, schema knowledge was tribal, and raw LLM-generated queries were unsafe for production data planes.

Built Network Intelligence — an artifact-first platform where bounded discovery builds a governed World Map (semantic brain), NL questions flow through AnalyticalRequest → InvestigationPlan → PlanValidator → LiveQueryEngine, and hybrid retrieval (lexical + embedding + topology + RRF) assists navigation without granting execution authority.

System architecture

  • Frontend: React 19 + TypeScript 5.7 + Vite 6 — netintel-console v0.1.9, served from FastAPI static
  • API Gateway: FastAPI monolith on port 8012 — Bearer auth, role gates, SSE sync stream
  • Intelligence: 565 Python modules — operator (110), universe (159), discovery (77), catalog (37), semantics (34)
  • World Map: Read-only derived navigation layer over JSON catalog stores — never queries ES or invokes LLMs directly
  • Retrieval: LocalVectorIndex + SemanticWorldIndex + hybrid_retrieval.py (RRF fusion) + Jina reranker
  • Data Plane: SafeElasticClient → LiveQueryEngine — multi-cluster ES with API key or credential auth
  • AI Plane: Ollama-first local stack — swappable to HuggingFace or mock backends for testing
