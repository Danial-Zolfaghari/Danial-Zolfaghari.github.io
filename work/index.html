Selected Engineering Work — Danial Zolfaghari

Portfolio of practical software, security, network operations, and backend engineering projects by Danial Zolfaghari (دانیال ذوالفقاری). The projects include production-oriented case studies and open-source tools with direct GitHub links.

Monitoring, security, AI and platform projects

  • VIDA — Self-hosted IT operations monitoring platform — unified console for Elasticsearch, servers, platform APIs, databases, and agent metrics.
  • AI Data Analyzer — AI-powered network/security intelligence platform — federated Elasticsearch discovery, governed semantic World Map, and bilingual NL investigations through validated live
  • ANDE — Read-only network traffic analysis console for L3/L4 DoS/DDoS triage — Layer-1 heuristics, Discovery proposals, Admin ground truth, and offline ML scoring over Elasticsea
  • Nexus Core — Proprietary FiveM server framework — player lifecycle, groups, inventory exports, paycheck loops, world safety, and spawn orchestration instead of off-the-shelf ESX, QBCo
  • Living Economy — Real-money ecosystem with ledger authority, dynamic pricing from actual player activity, inflation index, wealth tax, and commodity exchange — spending and income behave
  • Server Analytics — Standalone Flask Command Center running outside the game process — read-only MySQL, separate SQLite security layer, KPI dashboards, Activity Score analytics, and 15+ oper
  • ProcDomainSniffer — Native Windows desktop tool that correlates process activity with DNS observations, domains, IP addresses and network endpoints.
  • TunnelGate — Windows desktop application for reverse SSH tunnels and local SOCKS proxies, with encrypted local storage, independent workers and automatic reconnect.
  • DZ Operations Console — Flask-based Windows diagnostics and administration console with system monitoring, scheduled power actions and authentication-gated controls.
  • ELK-Checker — Cross-platform monitoring dashboard for scheduled Elasticsearch checks, rule evaluation, state history and alert delivery.
  • Round-Robin — Python toolkit for hostname discovery, DNS validation, public IP enrichment and SQLite-backed analysis through an interactive CLI.
