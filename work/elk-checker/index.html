Project developed by Danial Zolfaghari (دانیال ذوالفقاری). Monitoring · Open Source.

Project overview

Cross-platform monitoring dashboard for scheduled Elasticsearch checks, rule evaluation, state history and alert delivery.

Public engineering project with source code and documentation available on GitHub.

Build a practical tool for a focused engineering workflow.

Practical use cases

The application evaluates Elasticsearch query results against configured rules and tracks their resulting states over time. Scheduled checks support recurring monitoring instead of manual queries. Notifications can be dispatched through supported channels when rule conditions are met. The dashboard combines check configuration, evaluation history and alert orchestration in a Flask-based workflow.

Implementation context

Operators can use ELK-Checker to consolidate configured Elasticsearch checks and recurring evaluation in one dashboard. The application maintains status information and past outcomes so monitoring results can be reviewed over time. Configuration of checks, rule evaluation and delivery integrations are separate concerns, helping the interface present a clear operational sequence. As a public engineering project, its repository includes documentation of the Flask application and the supported Elasticsearch and notification integrations.
