Nexus Core — Proprietary Server Framework

Custom core · Not ESX / QBCore

Project developed by Danial Zolfaghari (دانیال ذوالفقاری). Platform · FiveM.

Project overview

Proprietary FiveM server framework — player lifecycle, groups, inventory exports, paycheck loops, world safety, and spawn orchestration instead of off-the-shelf ESX, QBCore, or VRP.

The foundation layer every other resource on the server depended on — a custom getSharedObject pattern, MySQL-backed persistence, and admin command registration built from scratch for a 120+ resource production platform.

Replaced template cores with a platform layer engineered for the server's exact economy, jobs, and admin model — every downstream system consumed the same shared object and persistence contracts.

Off-the-shelf FiveM cores forced compromises on economy rules, job systems, and admin workflows — and every downloaded pack assumed a different core API.

Authored Nexus Core as the single platform layer: shared object exports, player lifecycle, groups, paycheck loops, world safety, and admin registration — so 120+ custom resources shared one contract.

  • Safety: World module — spawn timing, explosion/fire suppression, weapon config
  • Consumers: 120+ downstream resources — economy, jobs, admin, analytics bridges
