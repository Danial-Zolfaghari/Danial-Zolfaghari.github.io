ProcDomainSniffer

Windows process-aware network telemetry

Project developed by Danial Zolfaghari (دانیال ذوالفقاری). Security · Open Source.

Project overview

Native Windows desktop tool that correlates process activity with DNS observations, domains, IP addresses and network endpoints.

Public engineering project with source code and documentation available on GitHub.

Build a practical tool for a focused engineering workflow.

Practical use cases

The Windows application connects process selection with network observations to help differentiate traffic associated with individual programs. Captured DNS information, resolved IPs and endpoint records can be reviewed with filtering and export workflows. Its focus is process-oriented troubleshooting, domain visibility and correlating network activity with the application responsible for it.

Implementation context

A typical investigation begins by selecting a running process and observing its associated network activity. DNS observations and resolved endpoint records provide context for connections, while grouping and filtering help focus the analysis on specific domains or addresses. Because the interface combines process selection with telemetry and export operations, the same workflow can support troubleshooting, network diagnostics and reviewing unexpected application communication. The README documents the role of TShark and Npcap in collecting packet-derived observations.
