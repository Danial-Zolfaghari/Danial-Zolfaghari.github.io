Project overview

Self-hosted IT operations monitoring platform — unified console for Elasticsearch, servers, platform APIs, databases, and agent metrics.

Self-hosted IT operations monitoring platform — unified console for Elasticsearch, servers, platform APIs, databases, and agent metrics with centralized alerting and multi-channel dispatch.

Production monitoring nerve center — replaces fragmented tools with one console for detection, triage, dispatch, and team collaboration across IRT/SOC operations.

Operations teams juggled multiple disconnected tools for Elasticsearch, server health, API monitoring, and alert dispatch — slowing incident response and creating blind spots during SOC shifts.

Engineered VIDA as a single self-hosted console with 8+ monitor types, centralized Alerts Center, multi-channel dispatch (SMS/call/Bale), team collaboration, and an offline-first AI assistant for config management.

System architecture

  • Frontend: Jinja2 + vanilla JS/CSS — 37 HTML templates, 88 JS modules
  • API: Flask blueprints with modular REST routes
  • Workers: Standalone scheduler — probes, agent deploy, read cache
  • Data: PostgreSQL with pg_compat abstraction layer
  • Integrations: Elasticsearch, Paramiko SSH, Kavenegar, Bale, Ollama
