TunnelGate

Native Windows SSH tunnel manager

Project developed by Danial Zolfaghari (دانیال ذوالفقاری). Security · Open Source.

Project overview

Windows desktop application for reverse SSH tunnels and local SOCKS proxies, with encrypted local storage, independent workers and automatic reconnect.

Public engineering project with source code and documentation available on GitHub.

Build a practical tool for a focused engineering workflow.

Practical use cases

The tool manages SSH connections through a native desktop interface, with separate workers handling tunnel lifecycles. Its workflow brings proxy configuration, encrypted local settings, health checks and reconnect logic together, while its Windows distribution includes an installer. This provides a repeatable way to manage reverse tunnels and local SOCKS connections.

Implementation context

The project targets repeated administration of configured SSH tunnels from a Windows desktop, including local proxy and reverse-tunnel scenarios. Operators can manage connection details, review the status of running tunnel workers and use reconnect logic where needed. The native WPF interface presents these tasks without requiring a separate terminal command for every connection. The repository documents its Windows-only desktop support, packaging and available release assets.
