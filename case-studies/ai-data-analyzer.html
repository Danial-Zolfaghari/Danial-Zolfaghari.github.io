CASE STUDY / APPLIED AI

AI Data Analyzer

Grounded natural-language analysis over a large Elasticsearch environment, designed to clarify ambiguity, constrain execution and attach evidence to every answer.

Sanitized architecture write-up — private infrastructure, customer data, credentials and deployment-specific identifiers are intentionally omitted.

The problem

Make a very large Elasticsearch environment usable through natural language for operators who should not need to know index names, field mappings or Query DSL. The difficult part is not generating a query — it is preventing the model from inventing schema, silently resolving ambiguous language, or answering without evidence.

Architecture

User question→Clarification→Retrieval→Semantic World Map→Planner→Deterministic DSL→Safe Elasticsearch→Evidence→Answer

Clarification first

Ambiguous terms are treated as unresolved data mappings. The system asks before guessing when multiple meanings remain plausible.

Semantic World Map

A persistent semantic layer maps human concepts to observed schema knowledge and distinguishes confirmed, stale, incomplete and hypothetical relationships.

Deterministic execution

The model interprets and plans; constrained application logic builds the final Elasticsearch request. Query authority does not live in free-form model output.

Evidence chain

User intent, plan, query, result and answer stay connected so unsupported claims can be rejected or inspected.

Scale changes the design

The target environment is multi-billion-document Elasticsearch with a large, evolving schema. Full-schema prompting does not scale. Retrieval has to be selective, schema trust needs lifecycle states, and model context must be earned by relevance rather than volume.

Key engineering lessons

  • LLM confidence is not schema confidence.
  • Retrieval quality matters more than sending more context.
  • Read-only enforcement belongs below the model layer.
  • Semantic mappings need trust states and lifecycle management.
  • Evidence should be a first-class artifact.
